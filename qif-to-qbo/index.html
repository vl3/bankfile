    QIF is the format personal finance software used for decades, and plenty of banks still offer it. Current versions of QuickBooks don’t import QIF bank files, so older history gets stuck.

    Bankfile reads QIF bank and credit card accounts, including the odd date styles QIF is known for (1/ 5’26, 01.05.2026), and writes a QBO file QuickBooks imports.

    How to convert

    1. Drop the .qif file above.
    2. Check the dates in the preview. If day and month look swapped, change the date order.
    3. Pick the account type and your bank, then download the .qbo file.
    4. In QuickBooks Desktop: File → Utilities → Import → Web Connect Files, then pick the account and match transactions in the Bank Feeds center.
    5. In QuickBooks Online: Transactions → Bank transactions → Link account ▾ → Upload from file, choose the .qbo file and map it to an account.

    Questions

    My QIF file has several accounts in it

    Bankfile reads the bank or credit card transactions in the file. If it holds several accounts, export each account to its own QIF first so they land in the right QuickBooks accounts.

    Can I convert QBO or CSV to QIF instead?

    Yes. Drop any supported file and choose QIF as the output.

    Is my bank statement uploaded anywhere?

    No. Bankfile reads and converts the file inside your browser, with the code on this page. There is no server that receives it, no account and no tracking script. Open your browser’s network panel while you convert and you’ll see the file never leaves your computer.
